# Catppuccin for lazygit

Only the themes referenced in `tools/fish/config/machines/*.fish` are kept here.

To add another flavor or accent:

1. Download it from https://github.com/catppuccin/lazygit (`themes-mergable/<flavor>/<accent>.yml`)
2. Save it as `<flavor>/<accent>.yml` in this folder
3. Point `LAZYGIT_THEME` in a machine file to it (path without `.yml`)
